# درجة 4T (نقص الصفائح المحرض بالهيبارين)

[الشروط والمصادر والأذونات](https://elucenia.org/ar/tools/4ts-trombocitopenia-por-heparina)

## كيفية الاستخدام

استخدم الأداة في البوابة أو افتح index.html عبر خادم HTTP محلي. اختر اللغة، وأكمل الحقول، ثم أجرِ الحساب.

## المدخلات والوحدات

### نقص الصفائح الدموية

`trombo`

- `0` — انخفاض \< ٣٠% أو أدنى عدد \< ١٠٬٠٠٠/µL
- `1` — انخفاض من ٣٠% إلى ٥٠% أو أدنى عدد من ١٠٬٠٠٠ إلى ١٩٬٠٠٠/µL
- `2` — انخفاض \> ٥٠% وأدنى عدد ≥ ٢٠٬٠٠٠/µL

### توقيت انخفاض الصفائح

`tempo`

- `0` — انخفاض قبل اليوم ٤ دون تعرّض حديث
- `1` — متوافق مع اليوم ٥–١٠ لكن غير مؤكّد؛ بعد اليوم ١٠؛ أو خلال ≤ ١ يوم مع تعرّض للهيبارين قبل ٣٠ إلى ١٠٠ يوم
- `2` — بداية واضحة بين اليوم ٥ واليوم ١٠، أو خلال ≤ ١ يوم مع تعرّض للهيبارين في آخر ٣٠ يوم

### خثار أو مضاعفات أخرى

`trombose`

- `0` — لا شيء
- `1` — خثار متفاقم أو متكرّر، آفة جلدية غير نخرية، أو اشتباه بالخثار
- `2` — خثار جديد مؤكّد، نخر جلدي، أو تفاعل جهازي بعد جرعة دفعة واحدة

### أسباب أخرى لنقص الصفائح

`outras`

- `0` — مؤكدة
- `1` — ممكنة
- `2` — لا سبب ظاهر

## إصدار الطريقة

4Ts/Lo 2006: 4 مجالات 0–2، مجموع 0–8؛ سياق ASH 2018

## المعادلة الموثقة

أربعة بنود، كل منها 0 إلى 2: T نقص الصفائح · T التوقيت · T الخثار · T الأسباب الأخرى. الحد الأقصى: 8.

## الحدود والفئة السكانية

يقدّر الاحتمال السريري قبل الاختبار عند الاشتباه بنقص الصفائح الناجم عن الهيبارين (HIT) بعد التعرض للهيبارين. يعتمد على تاريخ الصفائح والتوقيت والخثار والأسباب البديلة. لا تؤكد النتيجة وجود HIT؛ وقد اختلفت القيم التنبؤية بين السياقات المدروسة.
